# Role & Context
You are a Principal Software Engineer, Computer Science Professor, and Competitive Programming Coach. Help me create a complete "Zero to Expert" self-learning bootcamp for Data Structures and Algorithms (DSA) tailored for modern Software Engineers and high-level technical interviews.

# Target Structure
Generate all files inside a folder named `/data-structures-algorithms`. Split into 3 levels. Each level must contain:
1. `README.md`: คำอธิบายทฤษฎี คอนเซปต์กลไกการทำงาน วิเคราะห์ Complexity อย่างละเอียดเป็นภาษาไทย พร้อม Best Practices ในการเลือกใช้
2. Source code files: โค้ดตัวอย่างการเขียน Data Structure และ Algorithm จากศูนย์ (Clean, readable code using Python, JavaScript/TypeScript, or Go)
3. `LAB.md`: โจทย์ปัญหาอัลกอริทึมจากสถานการณ์จำลอง (อิงแนวทาง LeetCode/HackerRank) เป็นภาษาไทย พร้อมเฉลยโค้ดและวิธีคิดแบบทีละสเต็ปทั้งวิธี Naive และ Optimized Solution

# Detailed Curriculum
## 1. Beginner Level (Complexity Foundations & Linear Data Structures)
- Algorithmic Analysis: Understanding **Big O Notation**. Time and Space Complexity analysis (O(1), O(log n), O(n), O(n log n), O(n²)).
- Linear Data Structures: Implementation and operations of Arrays, Linked Lists (Singly vs Doubly), Stacks (LIFO), and Queues (FIFO).
- Basic Searching & Sorting: Two Pointers technique, Binary Search, and core sorting algorithms (Bubble, Insertion, Selection).

## 2. Intermediate Level (Non-Linear Structures & Algorithmic Paradigms)
- Hash Tables & Collections: Mechanism of Hashing, Collision resolution, and efficient usage of Hash Maps / Sets.
- Tree & Graph Architectures: Binary Trees, Binary Search Trees (BST), Tree Traversals (In-order, Pre-order, Post-order), and introduction to Graphs (Adjacency List vs Matrix).
- Traversal & Search Algorithms: Breadth-First Search (BFS) and Depth-First Search (DFS) applied to Trees and Graphs.
- Core Paradigms: **Recursion** fundamentals, Divide and Conquer (Merge Sort, Quick Sort), and the Greedy Approach.

## 3. Expert Level (Advanced Graph, Dynamic Programming, & Interview Patterns)
- Advanced Graph Algorithms: Shortest Path problems (Dijkstra's Algorithm), Minimum Spanning Tree (Kruskal's / Prim's), and Topological Sorting.
- Dynamic Programming (DP): Overlapping subproblems, Optimal substructure, Memoization (Top-Down) vs Tabulation (Bottom-Up) strategies (e.g., Knapsack, Longest Common Subsequence).
- Technical Interview Patterns: Mastering standard interview patterns: **Sliding Window**, Fast and Slow Pointers (Floyd's Cycle Detection), Backtracking (Subsets, Permutations), and Heap/Priority Queue patterns for Top K Elements.
- Performance Hardening: Memory optimization in loops, handling Edge Cases (Integer Overflow, Null pointers), and optimizing execution code for massive data scale.
