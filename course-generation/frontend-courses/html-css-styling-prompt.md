# Detailed Curriculum
## 1. Beginner Level (Semantic Web & Core Layout Engines)
- HTML5 Architecture: Semantic Tags (`<header>`, `<nav>`, `<main>`, `<article>`, `<aside>`, `<footer>`) for SEO and accessibility (ARIA roles).
- Modern CSS3 Layouts: Deep dive into **Flexbox** and **CSS Grid** (Grid areas, tracks, template lines) for absolute layout control.
- CSS Foundations: Understanding the Box Model, Specificity, Cascading rules, CSS Variables, Responsive Design with Media Queries, and CSS Animations/Transitions.

## 2. Intermediate Level (CSS at Scale & Utility-First Revolution)
- SASS/LESS Power Tools: Structuring styles using the 7-1 Pattern, Nesting, Variables, Mixins (`@mixin` / `@include`), Functions, and `@extend` inheritance.
- Tailwind CSS Mastery: The Utility-First paradigm. Configuring `tailwind.config.js` (Custom themes, colors, screens, plugins), handling Dark Mode dynamically, and using arbitrary values.
- Component Composition: Creating reusable UI components (Buttons, Inputs, Modals) using Tailwind CSS without code duplication (using tools like `clsx` or `tailwind-merge`).

## 3. Expert Level (Enterprise Component Design Systems & Optimization)
- Material-UI (MUI) Architecture: Theme Customization (`createTheme`, `ThemeProvider`), Overriding component styles globally, and adapting responsive styles using `sx` prop vs `styled` components.
- Advanced Interaction Patterns: Building fluid, complex dynamic data grids and complex form designs with validation styling using MUI or Tailwind. Managing layout shifts (CLS reduction).
- Production UI Engineering & Performance: Implementing CSS Purging, Tree Shaking for UI libraries, Custom CSS-in-JS optimization, designing scalable Fluid Typography, and preparing responsive components for Server-Side Rendering (SSR) environments like Next.js/Nuxt without style hydration mismatch.
